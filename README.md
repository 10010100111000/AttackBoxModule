# AttackBoxModule — trytopwn 靶机仓库

本仓库存放网络安全训练靶机。新题制作之前，先看以下**统一题库规划**，不要仅按 HTB/OffSec 的机器名称随意追加题目。

| 文档 | 用途 |
| --- | --- |
| [Web 题型分类与难度标准](docs/WEB_TAXONOMY.md) | 一级/二级知识点、初级/中级/高级判定、专项与综合靶机区别 |
| [Web 题库现状与开发路线图](docs/WEB_ROADMAP.md) | 现有题型覆盖、缺口、九台优先候选、验收与交接步骤 |
| [可机读题库清单](catalog/web-curriculum.json) | 所有现有靶机的 `primary_category`、细分技能、CI/Worker 状态与待开发队列 |

### 新建靶机前的约定

1. 先在可机读清单中确认**缺失的漏洞细分知识点和难度档**，再筛选有来源、有真实受影响组件的靶机。
2. 一台机器只统计**一个主分类**；复合攻击链中的其他技术列在次要分类，不重复计算总体覆盖。
3. `代码合并`、`靶机攻击链 CI 通过`、`Worker 正式发布可用`是三个**不同状态**。
4. 复现真实漏洞；不得编写模拟漏洞接口、伪造提权或容器逃逸。未经独立验证不得写“已完成”。
5. 修改题型、验收证据或发布状态时同步更新 `catalog/web-curriculum.json` 与 `docs/WEB_ROADMAP.md`。

> 规划快照：2026-11-23。任何合并都不自动等于镜像已发布。开发中的真实漏洞靶机只能运行在隔离的训练环境中，禁止公网直连。
