# 场景

一台小型博客服务器提供文章浏览与媒体管理功能。站点内容不多，但后台仍保留着用于管理图片和插件的功能。

你受委托检查媒体管理流程是否会允许不可信文件影响服务器。

# 任务

在不破坏正常博客数据的前提下，调查媒体管理功能，取得应用服务账户的命令执行权限，并提交目标文件中的 Flag。
