# 3. 什么是 Linux

Linux 这一术语有时被用来指代一系列开源操作系统，但更准确的做法或许是用该术语来描述一个[内核](https://en.wikipedia.org/wiki/Kernel_(operating_system))，而这些操作系统正是以该内核为基础构建的。Linux内核的主要功能包括管理外围设备、处理与处理器和内存的通信、调度待执行任务、处理中断请求等。

内核、系统工具以及各类软件包共同整合，形成**发行版（distribution，distro）**。所谓发行版，是一套可安装、可自启动，并附带附加软件的完整系统。需要明确：Linux 不是操作系统，它只是内核，是各类发行版赖以运行的核心。内核负责管理并协调计算机的各类硬件设备，同时提供进程、内存、文件系统等基础能力。单独的内核，就像一台没有车身的发动机。
